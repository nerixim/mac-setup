# 開発者向けEN↔JA用語集

Issue・PR・コミット・ops文面・コードコメント向け。プロダクトのUI文言はそのリポジトリのガイドラインを正とする。

原則: **日本語の文に英語語幹を裸で挿さない**（ルー大柴化）。識別子・型名・コマンド・テーブル名はバッククォートで隔離する。カタカナ定着語は文脈ごとに使い分ける。

## 書き方の目安

1. **文は日本語、固有名詞は英語のまま**: `shadow_predictions`テーブルへ記録する
2. **カタカナ定着語はカタカナ**: キュー、フラグ、シャドー、バックフィル、ペイロード
3. **直訳漢語を疑う**: 結線・消化（チェック）・処遇・投下（deploy以外）
4. **比喩動詞**: 既定値は「既定する」、振分は「振り分ける／送る」。公開操作はON/OFF
5. **英語セクション見出しを避ける**: In/Out → 対象/対象外
6. **可観測性と監視を混ぜない**: ログ/トレース/メトリクスの能力は可観測性。アラームは監視

Issue・PR・ops文面を書くときは、投稿前にこの表を一度当たる。
